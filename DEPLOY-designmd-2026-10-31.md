## Rollback

- **Worker:** run `npx wrangler rollback <version id noted in step 4>`. Then `git revert` our commits and **push**, otherwise the next wrap-up deploy from origin re-ships them.

- **mcp_report.py:** report-only; there is nothing to roll back.

## Notes / decisions for the user

- `structuredContent` is gated on the `MCP-Protocol-Version` request header (>= 2025-06-18), because tools/list is cached by clients and is stateless here. Clients that don't send the header (some Cursor builds) keep the old text-only shapes, so it is backward compatible.
- The prompt `theme-my-shadcn-app` from the scope was **not** added: there is no shadcn tool yet (scope #1).
- Q8 (lean design-only endpoint) and Q9 (make_word_search validation) are not done; Q8 needs a decision.
