## Deploy steps (user)

Run from `../mgd-inspiration-tpl-r4` unless noted. Same order as r3: R2 first (nothing links it yet), then code, then rows, then purge.

1. **Bundle** (if not already, or after any re-run of the e2e: ids and ui/ keys come from one run):
   `SCRATCH=<dir> BW_DUMP=<dir>/dump bash tests/ind7_local_e2e.sh` then `python3 tests/bw_bundle.py <dir>/dump`
   writes `../deploy-bundle-2026-11-21/tpl-r4-beauty-{rows.sql,rollback.sql,r2.tsv}`.
2. **R2:** upload every line of `tpl-r4-beauty-r2.tsv` (`key \t path \t sha256 \t content-type`) to bucket `mgd-inspiration-images`
   (`wrangler r2 object put mgd-inspiration-images/<key> --file <path> --content-type <ct> --remote`), then read one zip back and hash it.
3. **Merge and deploy:** merge `tpl-r4-beauty` into the live branch (`museum-collection-2026-10`), record the current Worker version id for
   rollback (`npx wrangler deployments list`), then `npx wrangler deploy`.
4. **D1 rows:** apply each line of `tpl-r4-beauty-rows.sql` as its own `wrangler d1 execute mgd-inspiration --remote --command "<line>"`.
   Never `--file` (a remote file is an import and takes the DB offline). Idempotent (`WHERE NOT EXISTS` on id or source_url).
5. **Purge** Cloudflare `/inspiration/ui` (`.claude-tools/cf_purge.py` prefix purge).
6. **Live checks** (read only, curl/8.4.0 UA):
   ```
   python3 tests/bw_live.py https://madegooddesigns.com/inspiration
   node tests/bw_mcp.mjs https://madegooddesigns.com/inspiration
   IND=beauty-fitness python3 tests/hc_routes.py https://madegooddesigns.com/inspiration
   for I in real-estate restaurant wedding portfolio; do IND=$I python3 tests/hc_routes.py https://madegooddesigns.com/inspiration; done
   python3 tests/hc_routes.py https://madegooddesigns.com/inspiration
   ```

## Rollback

1. `npx wrangler rollback <recorded version id>` and purge `/inspiration/ui`. The tree reverts to six industries; gym-website is flat again.
2. Apply `tpl-r4-beauty-rollback.sql` (one `UPDATE ... status='removed'` matching id AND source_url of exactly the 102 rows; the n12 gym and salon rows are untouched).
3. Revert the merge on the live branch so the next wrap-up does not redeploy it. R2 files can stay; nothing links them once the Worker is back.
