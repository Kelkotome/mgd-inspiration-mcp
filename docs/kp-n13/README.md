# Keyword Planner notes, n13 template round (6-Nov-2026)

Google Ads Keyword Planner, worldwide, English, Nov 2024 to Oct 2026, run serially with `.claude-tools/gads_kw.py --trend --geo ""`.
Pass 1: 1,303 terms, about 200 niches in 4 forms ("X website template / website design / landing page / web design"), 1,185 returned.
Pass 2: 605 terms in 6 forms ("X website / websites / website examples / website templates / best X websites / website inspiration") plus 8 idea seed pairs, 448 returned.
3mo = last 3 months vs prior 3. YoY = last 3 months vs same 3 a year earlier. Figures are as reported. Nothing is estimated.

Files: selected-niches-2026-11-06.tsv (the 20 niches), not-selected-2026-11-06.tsv, raw-pass1, raw-pass2, ideas.

## What the data says
- Subspeciality search volume is small. "cardiology website" is 110/mo and "cardiology website design" 10/mo. Keyword Planner does not support a volume case for subspecialities on their own; they are built for depth and agent use, as the user asked.
- Almost every "... template" term is falling (medical website template 880, -25% 3mo, -46% YoY). This matches n12. "landing page design" 18,100 (+32% / +24%) is the rising head term.
- Rising terms with a sustained series, the ranking used here: financial advisor landing page 70 (+81% / +71%), ai agent website design 70 (+83% / +223%), cleaning service website design 210 (+67% / +20%), pest control landing page 140 (+56% / +165%), solar website design 110 (+55% / +45%), crm website design 170 (+45% / +51%), apartment website design 140 (+38% / +69%), cardiology website 110 (+26% / 0), hvac landing page 90 (+24% / +35%), clinic website 6,600 (+23% / +50%), cybersecurity website 2,400 (+14% / +6%), preschool website 720 (+12% / +20%), veterinary website 2,400 (+7% / +7%), coaching website 12,100 (+7% / +7%).
- Legal subspecialities are the weakest group: personal injury, immigration and family law are all at or below 90/mo and falling hard. Orthodontics 110-210 and falling, dental implants 30. The parent "dental website design" 2,400 is rising (+65% / +9%).

## Traps, do not reuse these numbers
- "museum website design" 5,400 (+98% YoY) merges "web design museum", a well-known archive site, so it is navigational. Not a design demand signal.
- "website design" and "web design" for one niche usually return the same merged series. Never add them together.
- "X website" terms (doctor website 90,500, automotive website 33,100, mental health website 4,400) are mixed intent and mostly consumers looking for a site. Use for direction, not as template demand.
- Single-month spikes, ignored: audiology website design (1,900 in one month, then 10), aesthetic clinic website design (1,300 in one month), best tax websites (seasonal).
